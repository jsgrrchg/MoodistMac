# iOS changelog

## 1.0.0 — Unreleased

- Native iPhone app for iOS 26+, with Liquid Glass navigation and playback controls.
- Offline library of 131 sounds and 123 curated mixes; simultaneous playback, per-track/global volume and crossfades.
- Favorites, recents, custom mixes, sleep timer and automatic mix rotation.
- Background audio/session handling, system media commands, optional mixing with other apps and AirPlay route selection.
- Shared JSON preferences with Mac, Files import/export and sharing.
- English, Spanish and Brazilian Portuguese; appearance, accent and accessibility preferences.

This version has not been uploaded to TestFlight. Device validation, asset provenance, icon/store readiness and signing remain release gates; see QA.md and RELEASE.md.
